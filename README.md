## 📖 What is DevPilot?

**DevPilot** is an open-source, full-stack developer assistant that eliminates the friction of navigating, understanding, and debugging complex codebases.

Instead of pasting disconnected snippets into generic chat windows or wading through thousands of lines of legacy code, DevPilot links directly to your **GitHub** account, asynchronously maps your repository tree, chunks and embeds the source code into **pgvector**, and provides an interactive conversational UI powered by **Spring AI** and **Next.js 16**.

Every answer generated by DevPilot is strictly grounded in the retrieved code chunks and includes **direct GitHub source citations** linking straight to the exact files and line numbers.

---

## 🎯 Which Problem Does It Solve?

| The Problem | How DevPilot Solves It |
| :--- | :--- |
| **Painful Codebase Onboarding** | Engineers spend weeks manually reading unfamiliar code to locate endpoints, data flows, and configurations. DevPilot answers architectural questions instantly from real code. |
| **AI Hallucinations & Generic Answers** | Off-the-shelf LLMs hallucinate functions that don't exist in your repo. DevPilot injects only verified code snippets into the prompt via Top-K semantic retrieval. |
| **Context Switching & Code Leaks** | Manually copying sensitive proprietary code into public web chats is insecure and disrupts workflow. DevPilot provides secure at-rest encryption and isolates queries per repository. |
| **Unverifiable Explanations** | General AI gives code advice without proof. DevPilot returns clickable citation badges (`file.ts#L42-L88`) that open directly in GitHub. |

## ✨ Key Features

- **🔐 Seamless GitHub OAuth2**: Login with your GitHub account; DevPilot automatically discovers your public and private repositories.
- **🛡️ AES Token Encryption at Rest**: GitHub Personal Access Tokens are encrypted with AES via Spring Security's `TextEncryptor` before storage.
- **⚡ Asynchronous Code Indexing**: Non-blocking background worker (`ThreadPoolTaskExecutor`) traverses Git trees, filters out binaries and vendor folders, and reports real-time progress.
- **🧠 Token-Aware Chunking & Embedding**: Chunks code by token boundaries (~200 tokens) using Spring AI's `TokenTextSplitter` and embeds with OpenAI's `text-embedding-3-small`.
- **🔍 Vector Similarity Search via pgvector**: Cosine distance similarity search indexed with HNSW inside PostgreSQL 16.
- **🌊 Real-time Server-Sent Events (SSE) Streaming**: Token-by-token streaming response directly to the browser for low-latency dialogue.
- **📌 Line-Level GitHub Citations**: Dynamic badge links that take you directly to the exact file and line ranges on GitHub.
- **🎨 Modern Developer UI**: Built with Next.js 16 (App Router), React 19, Tailwind CSS v4, dark/light themes, and markdown syntax highlighting with `@streamdown/code`.

## 🛠 Tech Stack

### Backend
- **Framework**: Spring Boot 4.1.0 with Java 21 LTS
- **AI & Vectors**: Spring AI 2.0.0 (OpenAI Chat + pgvector vector store)
- **Security**: Spring Security 4.1 (OAuth2 Client, AES token encryption)
- **Persistence**: Spring Data JPA & Hibernate with PostgreSQL
- **Concurreny**: Spring `@Async` ThreadPoolTaskExecutor
- **Streaming**: Spring WebMVC `SseEmitter`

### Frontend
- **Framework**: Next.js 16.2.12 (App Router)
- **UI Engine**: React 19.2.4 & TypeScript 5
- **Styling**: Tailwind CSS v4 + Radix UI / Shadcn UI components
- **State & Data Fetching**: TanStack React Query v5
- **Markdown & Code Rendering**: Streamdown & `@streamdown/code`
- **Icons & Theme**: Lucide React & `next-themes`

### Infrastructure & Database
- **Database**: PostgreSQL 16 with `pgvector`, `uuid-ossp`, and `hstore` extensions
- **Containerization**: Docker & Docker Compose
- **External APIs**: GitHub REST API v3, OpenAI Platform (GPT-4o / Embeddings)

## 🚀 Quick Start

### 1. Prerequisites
Ensure you have the following installed on your machine:
- **Docker** and **Docker Compose**
- **Java 21 JDK**
- **Node.js 20+** and **npm**
- A **GitHub OAuth Application** ([create here](https://github.com/settings/developers))
- An **OpenAI API Key** ([obtain here](https://platform.openai.com/api-keys))

---

### 2. Start PostgreSQL with pgvector

Launch the preconfigured PostgreSQL 16 container with `pgvector` enabled:

```bash
docker compose up -d
```

The database will be accessible at `localhost:5433` (DB: `devpilot`, user: `postgres`, password: `postgres`).

---

### 3. Configure & Run Backend

1. Navigate to the `backend/` directory:
   ```bash
   cd backend
   ```
2. Copy the example properties file:
   ```bash
   cp src/main/resources/application.properties.example src/main/resources/application.properties
   ```
3. Edit `src/main/resources/application.properties` with your credentials:
   ```properties
   # GitHub OAuth App Credentials
   spring.security.oauth2.client.registration.github.client-id=YOUR_GITHUB_CLIENT_ID
   spring.security.oauth2.client.registration.github.client-secret=YOUR_GITHUB_CLIENT_SECRET

   # OpenAI API Key
   spring.ai.openai.api-key=YOUR_OPENAI_API_KEY

   # Secret Key & Hex Salt for AES Token Encryption
   app.token-encryptor-password=your-super-secret-password-here
   app.token-encryptor-salt=a1b2c3d4e5f67890
   ```
4. Start the backend:
   ```bash
   ./mvnw spring-boot:run
   ```
   The backend will start at `http://localhost:8080`.

---

### 4. Configure & Run Frontend

1. Navigate to the `client/` directory:
   ```bash
   cd ../client
   ```
2. Copy the example environment file:
   ```bash
   cp .env.example .env.local
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## ⚙️ Configuration Reference

### Backend Properties (`application.properties`)

| Property | Default Value | Description |
| :--- | :--- | :--- |
| `server.port` | `8080` | Port for the Spring Boot server |
| `spring.datasource.url` | `jdbc:postgresql://localhost:5433/devpilot` | PostgreSQL JDBC connection URL |
| `spring.datasource.username` | `postgres` | Database username |
| `spring.datasource.password` | `postgres` | Database password |
| `app.frontend-url` | `http://localhost:3000` | Frontend URL for OAuth redirects |
| `app.cors.allowed-origins` | `http://localhost:3000` | Allowed origins for CORS |
| `app.token-encryptor-password` | *Required* | Secret passphrase for AES token encryption |
| `app.token-encryptor-salt` | *Required* | Hex-encoded salt (e.g. 16/32 hex characters) |
| `spring.security.oauth2.client.registration.github.client-id` | *Required* | GitHub OAuth Client ID |
| `spring.security.oauth2.client.registration.github.client-secret` | *Required* | GitHub OAuth Client Secret |
| `spring.ai.openai.api-key` | *Required* | OpenAI API Key |
| `spring.ai.openai.chat.options.model` | `gpt-4o-mini` | Chat model used for answering queries |
| `spring.ai.openai.embedding.options.model` | `text-embedding-3-small` | Embedding model for code chunks |
| `app.indexing.chunk-size` | `800` | Code character target chunk size (~200 tokens) |
| `app.indexing.max-file-bytes` | `102400` | Maximum file size to index (100 KB) |
| `app.github.api-delay-ms` | `50` | Rate-limiting pause between GitHub API blob fetches |

## 🔌 API Overview

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/auth/login-url` | Returns the GitHub OAuth redirect path |
| `GET` | `/api/auth/me` | Fetches current user profile and GitHub handle |
| `POST` | `/api/auth/logout` | Terminates session and clears `DEVPILOT_SESSION` cookie |
| `GET` | `/api/repos?refresh={true/false}` | Lists repositories (synced with GitHub when refresh=true) |
| `GET` | `/api/repos/{id}` | Gets details for a specific repository |
| `POST` | `/api/repos/{id}/index` | Triggers asynchronous code indexing |
| `GET` | `/api/repos/{id}/status` | Polls indexing progress (`PENDING`, `INDEXING`, `READY`, `FAILED`) |
| `POST` | `/api/chat/sessions` | Creates a new chat session for an indexed repo |
| `GET` | `/api/chat/sessions?repositoryId={id}` | Lists chat sessions for a repository |
| `GET` | `/api/chat/sessions/{id}` | Retrieves message history for a session |
| `POST` | `/api/chat/sessions/{id}/messages` | Streams RAG answer via Server-Sent Events (`text/event-stream`) |
